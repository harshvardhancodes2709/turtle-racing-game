# turtle-racing-game
A Python Turtle Racing Game where 2–10 colorful turtles race to the finish line, with randomly generated movement determining the winner.

# Turtle Racing Game

A fun, interactive racing game built with Python's Turtle graphics module. Choose the number of racers and watch colorful turtles compete to reach the finish line!

## Features
- Supports 2–10 racers.
- Colorful turtle characters.
- Random movement for each racer.
- Automatically determines the winner.
- Graphical racing window using Turtle graphics.

## Requirements
- Python 3
- Tkinter support for Turtle graphics

## How to Run

1. Clone or download this repository.
2. Open the project folder in your terminal.
3. Run the following command:

```bash
python3 turtle_racing.py
```

## How to Play

1. Run the program.
2. Enter the number of racers between 2 and 10.
3. Watch the turtles race toward the finish line.
4. The first turtle to reach the finish line wins.
5. The winning turtle's color is displayed in the terminal.

## Technologies Used
- Python
- Turtle graphics
- Random module
- Loops and conditional statements
- Functions and lists
